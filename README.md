# RTS-SAT (Real-Time System Schedulability Analysis Tool)

This project is a real-time task scheduling simulator and analysis tool written in C++.

## Compilation
Compile by running the Makefile with ```make``` in the terminal, assuming the g++ toolchain (and make) is installed.
Clean by running ```make clean```, and debug with ```make debug```.
Run unit tests with ```make test```.

## Running
When compiling, the resulting binary is called rts-sat.exe (will be placed in /bin). So just execute this file. Feel free to experiment with all the functionality in main.cpp

After exporting a schedule to csv, it can be visualized by running ```python schedule_visualizer.py``` (it will look for a file named "schedule.csv"). Currently, the script cannot show schedules from EDF (since the script currently relies on priorities to order tasks from top to bottom, and with EDF tasks don't receive static priorities).
